# نظام إشعارات شبكة الواي فاي (WiFi Notifier)

نظام متكامل وخفيف لإرسال تنبيهات فورية (Push Notifications) لشاشات قفل الهواتف المتصلة بالواي فاي عبر كود QR مطبوع أو رقمي.

## 🚀 تشغيل النظام:
افتح الترمينال وشغّل:
```bash
cd /Users/megastore/.gemini/antigravity/scratch/wifi-notifier
./start.sh
```

## 📱 الروابط:
- **لوحة تحكم المدير**: [http://localhost:5001](http://localhost:5001) أو من الهاتف [http://192.168.1.3:5001](http://192.168.1.3:5001)
- **كارت الواي فاي والـ QR القابل للطباعة**: [http://localhost:5001/card](http://localhost:5001/card)
- **رابط قناة التنبيهات المباشر**: `https://ntfy.sh/nabil-wifi-alerts-99`

## 💡 كيفية الاستخدام:
1. ادخل على لوحة التحكم وعدل اسم شبكة الواي فاي والباسورد واضغط "حفظ".
2. افتح صفحة الكارت [http://localhost:5001/card](http://localhost:5001/card) واطبعه أو اعرضه.
3. كل شخص يمسح كود التنبيهات ويضغط "Subscribe" في ثانية واحدة.
4. من لوحة التحكم، اكتب أي رسالة واضغط "إرسال الإشعار لجميع الأجهزة الآن".
